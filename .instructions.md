# PocketSurge — Project Rules & Conventions

> This file documents the project structure, content conventions, image generation rules, and best practices. Any AI agent working on this project MUST read and follow these rules.

---

## 1. Project Overview

- **Framework:** Next.js 15 (App Router), TypeScript, Tailwind CSS
- **Static export:** `output: "export"` — generates static HTML in `out/`
- **Content source:** JSON files in `content/` directories, parsed at build time via Node.js `fs`
- **Styling:** Tailwind CSS with `@tailwindcss/typography` for article prose

---

## 2. Content Folder Structure

Each article lives in its own folder under `content/`:

```
content/
  ARTYYYYMMDD-NNN-i/
    article.json        # Article body + metadata
    metadata.json       # OpenGraph/Twitter card metadata
    seo.json            # SEO data, headings, links, structured data
    faq.json            # FAQ items
    image-prompts.json  # Image generation prompts
    images/
      hero.webp         # Hero image (1200×514, 21:9)
      image-2.webp      # Gallery image 1 (1024×768, 4:3)
      image-3.webp      # Gallery image 2
      image-4.webp      # Gallery image 3
```

### Folder Naming Convention

```
ARTYYYYMMDD-NNN-i
```

| Part | Meaning | Example |
|------|---------|---------|
| `ART` | Article prefix (fixed) | `ART` |
| `YYYYMMDD` | Date of generation | `20260722` |
| `NNN` | Sequential number (001–999) | `001` |
| `-i` | Marks that images have been generated | `-i` |

**Rules:**
- New articles (without images yet) use `ARTYYYYMMDD-NNN` (no `-i`)
- After images are generated, append `-i` to the folder name
- This makes it easy to identify which articles still need image generation

### Slug

Each `article.json` has a `"slug"` field that MUST match the folder name exactly.

```json
{
  "slug": "ART20260722-020-i",
  ...
}
```

## 3. Image Generation — Available Backends

### Option A: Stable Diffusion Web UI (port 7860) ✅ WORKING
- SD 1.5 models (RealisticVision, epicrealism) — 24 GB RAM fits comfortably
- API: `/sdapi/v1/txt2img`
- **Speed:** ~1-2 min per image
- **Script:** `scripts/generate-article-images.py`
- 90 images generated in ~50 min

### FLUX.1 Dev — NOT YET AVAILABLE LOCALLY

Several approaches were attempted but none are practical on this 24 GB Mac:

| Method | Issue |
|--------|-------|
| **ComfyUI + FLUX fp8** | 22.7 GB loaded — RAM thrashing, ~90 min/image |
| **MLX mzbac 4-bit** | Uses quantized CLIP/T5 not supported by mlx-examples |
| **Diffusers FLUX** | Model gated on HuggingFace, requires accepted license |

**To use FLUX in the future:**
- Accept the FLUX.1-dev license on HuggingFace → set `HF_TOKEN` → run `scripts/generate-flux-diffusers.py`
- Or use a cloud API (Replicate, Fal.ai, BFL)

### Image Generation Rules (for SD Web UI)

### 3.1 Image Prompts JSON

Each article MUST have an `image-prompts.json` file:

```json
{
  "images": [
    {
      "id": "image-1",
      "prompt": "The image generation prompt text...",
      "style": "cinematic",
      "placement": "hero",
      "altText": "Alt text for accessibility",
      "caption": "Optional caption"
    }
  ]
}
```

**Fields:**
- `id`: `"image-1"` for hero, `"image-2"`+ for gallery
- `style`: One of `cinematic`, `photorealistic`, `3d-render`, `illustration`, `infographic`, `minimal`, `diagram`
- `placement`: `"hero"` or `"section-N"` (section number)
- First image (`id: "image-1"`) is always the hero image

### 3.2 Image Resolutions

| Type | Aspect Ratio | Dimensions | Retina (2x) |
|------|-------------|------------|-------------|
| Hero (hero.webp) | 21:9 | 1200×514 | 2400×1028 |
| Gallery (image-N.webp) | 4:3 | 1024×768 | 2048×1536 |

### 3.4 Model Settings

#### SD Web UI (RealisticVision)
- **Model:** `realisticVisionV60B1_v51HyperVAE`
- **Sampler:** `DPM++ 2M SDE`
- **Sampling Steps:** 20
- **CFG Scale:** 7

#### ComfyUI FLUX.1 Dev fp8 (RECOMMENDED)
- **Model:** `flux1-dev-fp8.safetensors` (11 GB, from `Kijai/flux-fp8`)
- **Text encoders:** `clip_l.safetensors` + `t5xxl_fp8_e4m3fn.safetensors` (from `comfyanonymous/flux_text_encoders`)
- **VAE:** `flux-vae-bf16.safetensors` (from `Kijai/flux-fp8`)
- **Storage locations:**
  - UNET: `ComfyUI/models/unet/`
  - CLIP: `ComfyUI/models/clip/`
  - VAE: `ComfyUI/models/vae/`
- **Steps:** 25
- **Guidance:** 3.5
- **Sampler:** `euler`
- **CFG:** 1.0 (FLUX uses guidance_embed, not traditional CFG)
- **Output format:** WebP (quality=85)

### 3.5 Prompt Style Enrichment

When sending prompts to SD, enrich them with style-specific suffixes:

| Style | Suffix |
|-------|--------|
| `cinematic` | `cinematic lighting, dramatic composition, epic, professional photography` |
| `photorealistic` | `photorealistic, ultra detailed, sharp focus, 8K, professional photography` |
| `3d-render` | `3D render, octane render, detailed textures, volumetric lighting, isometric` |
| `illustration` | `digital illustration, vector art, clean lines, vibrant colors, stylized` |
| `infographic` | `infographic style, clean layout, professional diagram, data visualization` |
| `minimal` | `minimalist, clean design, simple composition, flat colors, elegant` |
| `diagram` | `technical diagram, clean schematic, blueprint style, labeled, structured` |

### 3.6 Image Generation Workflow

1. Create `image-prompts.json` with prompts for each image
2. Run `scripts/generate-article-images.py` (uses `http://127.0.0.1:7860` SD API)
3. Script creates `images/` folder and saves `hero.webp` + gallery images
4. Rename folder from `ARTYYYYMMDD-NNN` → `ARTYYYYMMDD-NNN-i` (add `-i` suffix)
5. Update `slug` in `article.json` to match the new folder name

## 4. How Images Are Served

- Images are stored at `content/{slug}/images/`
- A symlink `public/content -> ../content` makes them accessible at `/content/{slug}/images/hero.webp`
- The `dev` and `build` scripts in `package.json` auto-create this symlink
- Set `output: "export"` and `images: { unoptimized: true }` in `next.config.ts`

### Image Discovery (`lib/content/loaders.ts`)

- `discoverImages()` scans `content/{slug}/images/` via `fs`
- Looks for `hero.webp` → generates `/content/{slug}/images/hero.webp`
- Looks for files matching `/^image-\d+\.webp$/` → generates gallery URLs

## 6. Image Generation Script

Located at `scripts/generate-article-images.py`:

- Connects to Stable Diffusion Web UI API at `http://127.0.0.1:7860`
- Reads `image-prompts.json` from each article folder
- Skips articles that already have images (safe to re-run)
- Saves WebP at proper resolutions
- Uses the universal negative prompt (above)

To regenerate a single image, delete the individual `.webp` file and run the script again.
